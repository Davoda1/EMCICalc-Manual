| Symptom | Check |
| --- | --- |
| Trigonometric answer differs from expectation | Verify DEG/RAD/GRAD and explicit angle units. |
| A result is rounded | Check Exact/Decimal, its =/≈ marker, notation and significant digits. |
| A function remains incomplete | Fill its boxed arguments; use Tab and F1 guidance. |
| A key inserts an unexpected function | Check SHIFT, ALPHA or REG; release held modifiers or exit the active layer. |
| A fresh result is blank | Startup, AC, incomplete input and invalid/pending previews can intentionally leave it blank. Press Enter on a complete expression. |
| Currency values do not refresh | Check connectivity, system certificate support, rate date and supported currencies. The last-good cache may still be displayed. |
| Graph is empty or has gaps | Add and enable a series, choose a useful range, select Plot and check the domain. |
| A workbench reports a limit | Read its status; simplify input, reduce the job size or rescale data rather than repeatedly submitting the same oversized request. |
| Preferences do not persist | Apply staged Desktop changes, check the shown profile path, close other instances and read any save-conflict message. |
| Portable application cannot find a library/plugin | Re-extract the whole matching package and retain its directory structure. |
| Linux cannot launch the binary | Check x86_64 architecture, glibc 2.38 or newer, executable permission and the graphical environment. |
