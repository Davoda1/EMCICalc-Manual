| Shortcut | Action |
| --- | --- |
| Ctrl+L / Ctrl+G / Ctrl+H | Calculate / Graph / History |
| Ctrl+, | Settings |
| Enter / Ctrl+Enter | Evaluate the calculator |
| Shift+Enter | Add a visual expression line break |
| F1 | Context help, or the Guide |
| F2 / F3 / F4 / F5 | SHIFT / ALPHA / angle mode / result mode |
| Ctrl+Shift+C | Copy result |
| Ctrl+M / Ctrl+R | Store / recall memory |
| Ctrl+Shift+M / Ctrl+Shift+Delete | Add to / clear memory |
| Alt+Up / Alt+Down | Browse expression history |
| Ctrl+Shift+T | Transform selected structured input |
| F11 | Fullscreen |
| Escape | Leave fullscreen, step back, or cancel the active calculator layer/action |

Tab and Shift+Tab traverse controls, except while visiting empty expression slots. In menu cards, arrow keys move between choices and Enter activates one. The main calculator shortcuts do not replace normal text editing in unrelated tool fields.
