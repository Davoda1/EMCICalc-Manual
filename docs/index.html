EMCICalc Desktop 1.0.0 — User Manual

EMCICalc combines a scientific calculator with graphing, conversions, saved results and mathematical workbenches. This manual covers the Windows and GNU/Linux desktop application. It uses the English interface labels; changing the interface language does not change the mathematics.

Start here

New to EMCICalc? Install and open the application, then make your first calculation. Already using it? Choose a chapter below, or use Search the manual to find a control or worksheet.

This manual uses English interface labels and covers version 1.0.0. Save and export your work before replacing a device or removing the application.
